# GSTU Admission Seat Planning Android App

This project is an Android-based university admission seat planning system developed during my B.Sc. studies.

The application was designed to support the management of university admission seats, student applications, and seat allocation across different departments and admission categories.

## 📌 Project Information

**Project:** Varsity Admission Seat Planning Portal with Android

**Platform:** Android

**Development Period:** December 2019

**University:** Gopalganj Science and Technology University (GSTU)

## 🎯 Project Objective

The main objective of this project was to develop a mobile-based system for managing university admission seat allocation.

The application helps organize admission-related information and supports seat planning according to different academic and admission criteria.

## 📱 Main Features

- Track available university admission seats
- Manage student application information
- Organize department-wise seat allocation
- Support admission category-based seat planning
- Maintain structured admission information
- Provide a mobile interface for admission-related management

## 🛠️ Technologies
